# Concurrent Web Scraper (Go CLI)

Высокопроизводительный консольный парсер веб-страниц, написанный на **Go (Golang)**. Позволяет собирать данные в многопоточном режиме с ограничением нагрузки на целевой сервер и выгружать результаты в `CSV`-файл.

---

## 🚀 Особенности

* **Высокая скорость:** Использование горутин (`goroutines`) и каналов (`channels`) для параллельного сбора страниц.
* **Безопасность нагрузки (Semaphore Pattern):** Ограничение количества одновременных HTTP-запросов (по умолчанию до 5 параллельных потоков).
* **Удобный CLI интерфейс:** Настройка параметров (URL, глубина страниц, выходной файл, количество потоков, задержки) через флаги командной строки.
* **Обработка ошибок:** Автоматическое продолжение работы при сбое загрузки отдельной страницы и корректная обработка статусов HTTP.

## 🛠 Установка и сборка

### Предварительные требования
* Установленный [Go 1.20+](https://go.dev/dl/)

### Сборка бинарного файла

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/your-username/go-concurrent-parser.git
   cd go-concurrent-parser
   ```

2. Установите зависимости и скомпилируйте исполняемый файл:
   ```bash
   go mod download
   go build -o parser main.go
   ```

   Для Windows:
   ```bash
   go build -o parser.exe main.go
   ```

## 📖 Использование

### Доступные флаги CLI

| Флаг | Тип | По умолчанию | Описание |
| :--- | :--- | :--- | :--- |
| `-url` | `string` | `https://quotes.toscrape.com` | Базовый URL целевого сайта |
| `-pages` | `int` | `5` | Количество страниц для обхода |
| `-out` | `string` | `output.csv` | Имя итогового CSV-файла |
| `-concurrency` | `int` | `5` | Максимальное количество параллельных потоков |
| `-delay` | `int` | `500` | Задержка между запросами в миллисекундах |

---

### Примеры запуска

**1. Простой запуск с параметрами по умолчанию:**
```bash
./parser
```

**2. Парсинг 10 страниц с сохранением в кастомный файл:**
```bash
./parser -pages=10 -out=quotes_10.csv
```

**3. Увеличение скорости (10 параллельных потоков без задержек):**
```bash
./parser -pages=20 -concurrency=10 -delay=0 -out=fast_scrape.csv
```
